Pipeline Architecture
Report Analysis → Classifier → conditional routing → Summary Agent → Recommendation Agent
Normal = early exit Abnormal = full pipeline Critical = alert + full pipeline

How to use this demo: Click each card's "Run" button in order. Each run will show you the pipeline status page, where you'll see the step-by-step progress and respond to any human-in-the-loop checkpoints.

🤝 Multi-Report Memory

After running the abnormal demo, the status page shows a "Chain Another Report" option. Use it to run a second report for the same patient — the summary will include a "Trend vs Previous" section comparing the two reports.

This demonstrates LangGraph thread state persistence and cross-report memory.
